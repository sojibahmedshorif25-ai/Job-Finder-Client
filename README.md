## 📖 Overview

Frontend for StartupForge — a startup team-building platform with role-based dashboards, startup management, and Stripe payment integration.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 👤 **Role Dashboards** | Founder / Collaborator / Admin |
| 🔐 **Authentication** | Secure login & registration |
| 🏢 **Startup CRUD** | Create & manage startups |
| 💳 **Stripe Payments** | Premium subscription |
| 🖼️ **Image Upload** | Profile & startup images |
| 📄 **Pagination** | Efficient data loading |
| 🔍 **Search** | Find opportunities |
